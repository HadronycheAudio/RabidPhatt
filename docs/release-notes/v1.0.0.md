The first release of RabidPhatt, a monophonic VST® 3 synthesizer: 66 sawtooth oscillators that a single control pulls apart and brings back together, for a sound that's thick, unstable and a little chaotic.

## What's in it

- **Motion:** spreads 32 oscillators per stereo side out from the note as it rises, up to 0.58 to 1.42 times the note, and converges them on it as it falls. The two sides use different spreads, and they never quite line up.
- **Motion LFO:** a sine wave that moves Motion, free running in Hz or synced to the tempo, from 4/1 down to 1/32 with dotted and triplets. A delay fades it in after a note starts.
- **Glide:** monophonic with last-note priority, and legato playing doesn't restart the envelopes.
- **Amp and filter envelopes:** a separate ADSR for each, shaping the level and a 24 dB/octave low-pass.
- **No latency:** notes start on their exact sample.

## Installing

Download `RabidPhatt-1.0.0-Setup.exe` below and run it. It installs to `C:\Program Files\Common Files\VST3`, which is where DAWs look by default, and you can remove it from Windows' Installed apps.

**Windows will probably warn you when you run it,** because the installer isn't code-signed. To continue, choose **More info**, then **Run anyway**.

## Requirements

- Windows 10 or later, 64-bit
- A VST 3 host. RabidPhatt is developed and used in Cubase, and other hosts haven't been tried.
