RabidPhatt is a monophonic VST® 3 synthesizer with 66 sawtooth oscillators. A single control pulls them apart and brings them back together. This release completes the LV2 version on Linux. On Windows and macOS, only the version number changed.

## What is new

- **The LV2 has the panel of the VST 3.** Your host opens the same window as with the VST 3.
- **The LV2 follows the tempo of the host.** With LFO sync on, the LFO now follows your project, as in the VST 3. In 1.3.0, it ran at a fixed 120 BPM.
- **The LV2 saves its own state.** Your host saves the exact values of the parameters with the project, and not only 32-bit control values.
- **A rare crash on Linux is fixed.** In rare automated tests, the test program crashed as it unloaded the plug-in. A font thread of the Pango library was still running inside the plug-in. A host that unloads plug-ins can crash in the same way. The plug-in now stays loaded until the host quits, in the VST 3 and the LV2.

## About the LV2

You cannot move settings between the LV2 and the VST 3, because hosts see them as different plug-ins.

- Projects saved with the LV2 of 1.3.0 open in this version. The URI and the ports did not change, so your host finds the plug-in and its control values.

## Before you rely on the LV2

**It was tried only briefly by a person,** in REAPER on Debian 13. Automated tests ran on Ubuntu 22.04 and 24.04 and Debian 12 and 13. They compare its output with the output of the VST 3, bit for bit. They also compare its panel with the panel of the VST 3, pixel for pixel. Other hosts are not tested.

The REAPER renders of the two formats are not quite identical. The VST 3 render replaces extremely quiet tails, below about -320 dB, with silence. The LV2 render keeps them. Outside REAPER, the output of the two formats is identical.

## Installing on Linux

There are two downloads, and you can have both:

- `RabidPhatt-1.4.0-Linux-x86_64.tar.gz` is the VST 3.
- `RabidPhatt-1.4.0-Linux-x86_64-LV2.tar.gz` is the LV2.

1. Extract the downloads into the folders where hosts look:
   ```bash
   mkdir -p ~/.vst3 ~/.lv2
   tar -xzf RabidPhatt-1.4.0-Linux-x86_64.tar.gz -C ~/.vst3
   tar -xzf RabidPhatt-1.4.0-Linux-x86_64-LV2.tar.gz -C ~/.lv2
   ```
2. On Debian or Ubuntu, install the libraries that they need:
   ```bash
   sudo apt install libxcb-cursor0 libxcb-util1 libxkbcommon-x11-0 libcairo2 libpango-1.0-0 libpangocairo-1.0-0
   ```
3. Restart your host. If it does not find RabidPhatt, rescan for plug-ins. In REAPER, add the `~/.lv2` folder under **Preferences**, **Plug-ins**, **LV2/CLAP**.

To remove them, delete `~/.vst3/RabidPhatt.vst3` and `~/.lv2/RabidPhatt.lv2`. To upgrade, delete those folders first, then extract the new version.

The tarballs are not signed.

## Installing on a Mac

**The Mac version is not yet tested in a real host on a real Mac.**

1. Download `RabidPhatt-1.4.0-macOS.pkg` below.
2. Double-click it. macOS refuses to open it the first time, because Apple did not sign the installer:
   - On macOS 14 or earlier, Control-click the file, choose **Open**, then **Open** again.
   - On macOS 15 or later, click **Done**, then open **System Settings**, go to **Privacy & Security**, scroll down, and click **Open Anyway**.
3. Follow the installer, which asks for your password. It puts the plug-in in `/Library/Audio/Plug-Ins`, where hosts look.
4. Restart your host.

## Installing on Windows

Download `RabidPhatt-1.4.0-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, where DAWs look by default. You can remove it from the Installed apps page of Windows.

The installer is not code-signed, so Windows shows a warning. To continue, choose **More info**, then **Run anyway**.

## Upgrading

The saved format did not change. On Windows and macOS, only the version number differs from 1.3.0, so you can skip this release there. On Linux, the VST 3 only gains the crash fix.

## Requirements

- Windows 10 or later, 64-bit, macOS 10.15 or later, or x86_64 Linux with glibc 2.34 or later, as on Ubuntu 22.04, Debian 12 or newer
- A VST 3 host, an LV2 host on Linux, or an Audio Unit host on a Mac. RabidPhatt is developed and used in Cubase, and was tried briefly in one other host, REAPER on Linux. On Linux, the host must embed plug-in windows through X11.
