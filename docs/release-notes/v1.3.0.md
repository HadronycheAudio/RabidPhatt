RabidPhatt is a monophonic VST® 3 synthesizer with 66 sawtooth oscillators. A single control pulls them apart and brings them back together. This release adds a first LV2 version on Linux. The code of the other formats did not change.

## What is new

- **LV2, on Linux:** an early version for x86_64. It runs the same sound engine as the VST 3, with audio, MIDI and all 19 parameters as controls. Automated tests compare its output with the output of the VST 3, bit for bit.

## What the LV2 does not do yet

- **It has no panel.** Your host shows its own generic controls. If you want the panel on Linux, use the VST 3.
- **It does not follow the tempo of the host.** With LFO sync on, the LFO runs at a fixed 120 BPM. It does not line up with the grid of your project.
- **It has no saved state of its own.** Your host saves its parameters as 32-bit control values, which rounds them slightly. The worst difference measured from the VST 3 was about 92 dB below full scale. No person listened for this difference.

You cannot move settings between the LV2 and the VST 3, because hosts see them as different plug-ins.

## Before you rely on the LV2

**No person listened to it yet.** A script played notes through it in `jalv`. Another script loaded and rendered it in REAPER on Debian 13. Automated tests ran on Ubuntu 22.04 and 24.04 and Debian 12 and 13. Other hosts are not tested.

The REAPER renders of the two formats are not quite identical. The VST 3 render replaces extremely quiet tails, below about -320 dB, with silence. The LV2 render keeps them. Outside REAPER, the output of the two formats is identical.

**The VST 3 has an unexplained crash.** The test that opens the panel crashed once on CI. The crash came as the test program exited, after all its checks passed. This happened once in about 33 runs, and about 260 further runs did not repeat it. The cause is not known, and it did not occur in a host. The LV2 has no panel, so this test does not apply to it.

## Installing on Linux

There are two downloads, and you can have both:

- `RabidPhatt-1.3.0-Linux-x86_64.tar.gz` is the VST 3, with the panel.
- `RabidPhatt-1.3.0-Linux-x86_64-LV2.tar.gz` is the LV2, with no panel.

1. Extract the downloads into the folders where hosts look:
   ```bash
   mkdir -p ~/.vst3 ~/.lv2
   tar -xzf RabidPhatt-1.3.0-Linux-x86_64.tar.gz -C ~/.vst3
   tar -xzf RabidPhatt-1.3.0-Linux-x86_64-LV2.tar.gz -C ~/.lv2
   ```
2. On Debian or Ubuntu, install the libraries that they need:
   ```bash
   sudo apt install libxcb-cursor0 libxcb-util1 libxkbcommon-x11-0 libcairo2 libpango-1.0-0 libpangocairo-1.0-0
   ```
3. Restart your host. If it does not find RabidPhatt, rescan for plug-ins. In REAPER, add the `~/.lv2` folder under **Preferences**, **Plug-ins**, **LV2/CLAP**.

To remove them, delete `~/.vst3/RabidPhatt.vst3` and `~/.lv2/RabidPhatt.lv2`. To upgrade, delete those folders first, then extract the new version.

The tarballs are not signed.

## Installing on a Mac

**The Mac version is not yet tested in a real host on a real Mac.**

1. Download `RabidPhatt-1.3.0-macOS.pkg` below.
2. Double-click it. macOS refuses to open it the first time, because Apple did not sign the installer:
   - On macOS 14 or earlier, Control-click the file, choose **Open**, then **Open** again.
   - On macOS 15 or later, click **Done**, then open **System Settings**, go to **Privacy & Security**, scroll down, and click **Open Anyway**.
3. Follow the installer, which asks for your password. It puts the plug-in in `/Library/Audio/Plug-Ins`, where hosts look.
4. Restart your host.

## Installing on Windows

Download `RabidPhatt-1.3.0-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, where DAWs look by default. You can remove it from the Installed apps page of Windows.

The installer is not code-signed, so Windows shows a warning. To continue, choose **More info**, then **Run anyway**.

## Upgrading

The saved format did not change. If you do not use the LV2, you can skip this release. For the VST 3 and the Audio Unit, only the version number differs from 1.2.0.

## Requirements

- Windows 10 or later, 64-bit, macOS 10.15 or later, or x86_64 Linux with glibc 2.34 or later, as on Ubuntu 22.04, Debian 12 or newer
- A VST 3 host, an LV2 host on Linux, or an Audio Unit host on a Mac. The author develops and uses RabidPhatt in Cubase, and tried it briefly in one other host, REAPER on Linux. For the VST 3 on Linux, the host must embed plug-in windows through X11.
