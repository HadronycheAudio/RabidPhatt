This release of RabidPhatt, a monophonic VST® 3 synthesizer with 66 sawtooth oscillators that a single control pulls apart and brings back together, adds Linux, as a VST 3. There's no LV2 version yet. On Windows and macOS, nothing you can hear or see should have changed.

## What's new

- **Linux:** a VST 3 for x86_64, for Ubuntu 22.04, Debian 12 or newer, or anything else with glibc 2.34 or later.

## Before you rely on it on Linux

**This is the first Linux release, and it has only been tried briefly by hand, in REAPER on Debian 13.** Automated tests ran on Ubuntu 22.04 and 24.04 and Debian 12 and 13, but nothing can check by machine how it sounds, or how its panel behaves in your host. Other hosts haven't been tried.

## Installing on Linux

1. Download `RabidPhatt-1.2.0-Linux-x86_64.tar.gz` below.
2. Extract it where hosts look:
   ```bash
   mkdir -p ~/.vst3
   tar -xzf RabidPhatt-1.2.0-Linux-x86_64.tar.gz -C ~/.vst3
   ```
3. On Debian or Ubuntu, make sure that you have the libraries it needs:
   ```bash
   sudo apt install libxcb-cursor0 libxcb-util1 libxkbcommon-x11-0 libcairo2 libpango-1.0-0 libpangocairo-1.0-0
   ```
4. Restart your host, and rescan for plug-ins if it doesn't find RabidPhatt.

To remove it, delete `~/.vst3/RabidPhatt.vst3`. To upgrade, delete that folder first, and extract the new version.

The tarball isn't signed.

## Installing on a Mac

**The Mac version still hasn't been used in a real host on a real Mac.**

1. Download `RabidPhatt-1.2.0-macOS.pkg` below.
2. Double-click it. **macOS will probably refuse to open it the first time,** because the installer isn't signed by Apple:
   - On macOS 14 or earlier, Control-click the file, choose **Open**, then **Open** again.
   - On macOS 15 or later, click **Done**, then open **System Settings**, go to **Privacy & Security**, scroll down, and click **Open Anyway**.
3. Follow the installer, which asks for your password. It puts the plug-in in `/Library/Audio/Plug-Ins`, which is where hosts look.
4. Restart your host.

## Installing on Windows

Download `RabidPhatt-1.2.0-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, which is where DAWs look by default. You can remove it from Windows' Installed apps.

**Windows will probably warn you when you run it,** because the installer isn't code-signed. To continue, choose **More info**, then **Run anyway**.

## Upgrading

The saved format hasn't changed. On Windows and macOS, only build and test code changed, and the panel code gained a Linux path that those platforms don't use, so this release wasn't compared with the previous one bit for bit. Projects using the VST 3 should move between Windows, Mac and Linux, but this hasn't been tried, and the audio won't necessarily be identical down to the last bit. An Audio Unit saves in its own format, so its settings can't be moved to the VST 3.

## Requirements

- Windows 10 or later, 64-bit, macOS 10.15 or later, or x86_64 Linux with glibc 2.34 or later
- A VST 3 host, or on a Mac an Audio Unit host. RabidPhatt is developed and used in Cubase, and has only been tried briefly in one other host, REAPER on Linux. On Linux, the host has to embed plug-in windows through X11.
