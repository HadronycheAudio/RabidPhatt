RabidPhatt is a monophonic VST® 3 synthesizer with 66 sawtooth oscillators that a single Motion control pulls apart and brings back together. This release moves its sound engine from C++ to Rust. The sound, the controls and the saved projects are the same.

## What is new

- **The sound engine is written in Rust:** the voice, with its oscillator banks, envelopes, LFO and filter. Rust checks memory use when it compiles, so a whole class of faults cannot happen in the engine. The code that connects the engine to the host, the panel and the installers stays in C++.
- **The sound did not change.** Automated tests compared this version with 1.4.0, sample by sample, over three seconds of audio at many settings, with saved projects and with damaged ones. Every sample, every saved state and every control's text came out identical, bit for bit.

## Before you rely on this version

**This version was not yet tried by a person in a host.** The automated tests ran on Windows, macOS and Linux, and they compared its output with the output of 1.4.0. They do not listen.

## Installing on Linux

There are two downloads, and you can have both:

- `RabidPhatt-1.5.0-Linux-x86_64.tar.gz` is the VST 3.
- `RabidPhatt-1.5.0-Linux-x86_64-LV2.tar.gz` is the LV2.

1. Extract the downloads into the folders where hosts look:
   ```bash
   mkdir -p ~/.vst3 ~/.lv2
   tar -xzf RabidPhatt-1.5.0-Linux-x86_64.tar.gz -C ~/.vst3
   tar -xzf RabidPhatt-1.5.0-Linux-x86_64-LV2.tar.gz -C ~/.lv2
   ```
2. On Debian or Ubuntu, install the libraries that they need:
   ```bash
   sudo apt install libxcb-cursor0 libxcb-util1 libxkbcommon-x11-0 libcairo2 libpango-1.0-0 libpangocairo-1.0-0
   ```
3. Restart your host. If it does not find RabidPhatt, rescan for plug-ins. In REAPER, add the `~/.lv2` folder under **Preferences**, **Plug-ins**, **LV2/CLAP**.

To remove them, delete `~/.vst3/RabidPhatt.vst3` and `~/.lv2/RabidPhatt.lv2`. To upgrade, delete those folders first, then extract the new version.

The tarballs are not signed.

## Installing on a Mac

**The Mac version is not yet tested in a real host on a real Mac.**

1. Download `RabidPhatt-1.5.0-macOS.pkg` below.
2. Double-click it. macOS refuses to open it the first time, because Apple did not sign the installer:
   - On macOS 14 or earlier, Control-click the file, choose **Open**, then **Open** again.
   - On macOS 15 or later, click **Done**, then open **System Settings**, go to **Privacy & Security**, scroll down, and click **Open Anyway**.
3. Follow the installer, which asks for your password. It puts the plug-in in `/Library/Audio/Plug-Ins`, where hosts look.
4. Restart your host.

## Installing on Windows

Download `RabidPhatt-1.5.0-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, where DAWs look by default. You can remove it from the Installed apps page of Windows.

The installer is not code-signed, so Windows shows a warning. To continue, choose **More info**, then **Run anyway**.

## Upgrading

The saved format did not change, and projects saved with earlier versions open as before. This version replaces 1.4.0 on all systems.

## Requirements

- Windows 10 or later, 64-bit, macOS 10.15 or later, or x86_64 Linux with glibc 2.34 or later, as on Ubuntu 22.04, Debian 12 or newer
- A VST 3 host, an LV2 host on Linux, or an Audio Unit host on a Mac. RabidPhatt is developed and used in Cubase, and was tried briefly in one other host, REAPER on Linux. On Linux, the host must embed plug-in windows through X11.
