This release of RabidPhatt, a monophonic VST® 3 synthesizer with 66 sawtooth oscillators that a single control pulls apart and brings back together, adds macOS, as a VST 3 and as an Audio Unit. On Windows, nothing you can hear or see has changed.

## What's new

- **macOS:** for Intel Macs and Apple Silicon, on macOS 10.15 or later.
- **Audio Unit:** for hosts such as Logic Pro and GarageBand, alongside the VST 3.

## Before you rely on it on a Mac

**This is the first macOS release, and it hasn't been used in a real host on a real Mac yet.** Automated tests ran on both kinds of Mac, including Apple's Audio Unit validation, but nothing can check by machine how it sounds, or how its panel looks in your host.

## Installing on a Mac

1. Download `RabidPhatt-1.1.0-macOS.pkg` below.
2. Double-click it. **macOS will probably refuse to open it the first time,** because the installer isn't signed by Apple:
   - On macOS 14 or earlier, Control-click the file, choose **Open**, then **Open** again.
   - On macOS 15 or later, click **Done**, then open **System Settings**, go to **Privacy & Security**, scroll down, and click **Open Anyway**.
3. Follow the installer, which asks for your password. It puts the plug-in in `/Library/Audio/Plug-Ins`, which is where hosts look.
4. Restart your host.

## Installing on Windows

Download `RabidPhatt-1.1.0-Setup.exe` below and run it. It replaces any previous version and installs to `C:\Program Files\Common Files\VST3`, which is where DAWs look by default. You can remove it from Windows' Installed apps.

**Windows will probably warn you when you run it,** because the installer isn't code-signed. To continue, choose **More info**, then **Run anyway**.

## Upgrading

The saved format hasn't changed. On Windows, audio, saved state and parameter text were compared with the previous version before this release, and they match. Projects using the VST 3 should move between Windows and Mac, but the audio won't be identical down to the last bit, because the two kinds of computer round numbers differently. An Audio Unit saves in its own format, so its settings can't be moved to the VST 3.

## Requirements

- Windows 10 or later, 64-bit, or macOS 10.15 or later
- A VST 3 host, or on a Mac an Audio Unit host. RabidPhatt is developed and used in Cubase, and other hosts haven't been tried.
